# 项目五 · 多平台标题搬家 + SEO 优化（PRD）

> 个人项目 / 实战练习。演示模式使用规则模板生成，示例数据公开。

## 1. 背景与痛点
- 同一款商品要在淘宝 / 拼多多 / 抖音 / 小红书分发，各平台字数上限、搜索逻辑、内容风格完全不同，手动改写费时。
- 改写过程中容易带入极限词（"最""第一"），跨平台发布时违规风险翻倍。

## 2. 目标
输入一个原标题 + 类目 + 卖点，一键输出四平台适配标题：自动匹配字数上限与风格，并逐条过违禁词检测。

## 3. 用户故事
- 作为商家，我输入"头层牛皮托特包 大容量通勤"，得到淘宝（≤30 字搜索堆词）、拼多多（≤60 字营销堆词）、抖音（≤55 字口播钩子）、小红书（≤20 字种草风）四个版本。
- 作为商家，如果生成结果命中违禁词，我要看到标红提示，避免直接复制发布被罚。

## 4. 功能范围
| 模块 | 说明 |
|---|---|
| 平台规则配置表 | 四平台的字数上限 + 风格模板，一处配置可扩展新平台 |
| 适配生成 | 演示模式用规则模板拼装；接入大模型可升级为语义改写（复用项目二接入方式） |
| 违禁词检测 | 本地词表逐条检测并前端标红（与项目二同一套词表思路） |

## 5. 非目标（边界，面试主动说明）
- 不做真实平台发布；不做关键词搜索量分析（需平台数据接口）。
- 违禁词表为示例，实际使用需按最新广告法与平台规则维护。

## 6. 设计亮点（面试可讲）
- **平台差异配置化**：字数上限和风格模板是配置不是硬编码，体现"规则可维护"意识。
- **生成 + 合规闭环**：每条生成结果强制过违禁词检测，复用项目二的合规思路，形成方法论一致性。

## 7. 运行
```bash
pip install -r requirements.txt
python app.py   # http://127.0.0.1:5004
```
演示模式无需 API key。
