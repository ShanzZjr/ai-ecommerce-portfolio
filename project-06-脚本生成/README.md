# 项目六 · 短视频 / 直播脚本批量生成（PRD）

> 个人项目 / 实战练习。演示模式使用结构模板生成，示例公开。

## 1. 背景与痛点
- 每条短视频 / 每场直播都要现想脚本，一人店精力不够；写出来的内容结构不稳定，时好时坏。
- 好的带货脚本有固定方法论（钩子-共鸣-卖点-行动 / 开场-过款-逼单），完全可以结构化沉淀。

## 2. 目标
输入商品 / 卖点 / 价格 / 人群，一键产出：2 版短视频分镜脚本（含时间轴、台词、画面建议）+ 1 段口播稿 + 直播三段话术。

## 3. 用户故事
- 作为商家，我输入"托特包 / 大容量,百搭,耐磨 / 129 / 通勤女生"，得到可直接开拍的分镜表和可照读的口播稿。
- 作为商家，同一商品我想快速出不同开场版本做 A/B 测试（痛点开场 vs 悬念开场）。

## 4. 功能范围
| 模块 | 说明 |
|---|---|
| 短视频脚本 | 四段式结构（0-3s 钩子 / 3-10s 共鸣 / 10-25s 卖点 / 25-30s 行动号召），每段含台词与画面建议 |
| 口播稿 | 按卖点顺序组织，控制在约 40 秒语速 |
| 直播话术 | 开场欢迎 / 过款介绍 / 逼单节奏 三段模板 |
| 结构模板化 | 脚本方法论沉淀为配置，一换模板即可适配其他内容形态 |

## 5. 非目标（边界，面试主动说明）
- 不做真实视频生成 / 直播切片（需素材与算力）；不保证话术合规——发布前仍需过项目二/五的违禁词检测。
- 演示模式为模板拼装；接入大模型可按品类风格改写台词（复用项目一/二接入方式）。

## 6. 设计亮点（面试可讲）
- **结构确定、内容可升级**：脚本骨架用规则保证稳定输出，台词交给大模型润色——和项目三"先规则后模型"同一方法论。
- **批量与 A/B**：一次生成两个开场版本，天然支持内容 A/B 测试。

## 7. 运行
```bash
pip install -r requirements.txt
python app.py   # http://127.0.0.1:5005
```
演示模式无需 API key。
